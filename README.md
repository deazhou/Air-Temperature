#  Air Temperature Prediction using LSTM

This project builds a **deep learning model** using **LSTM (Long Short-Term Memory)** to forecast **air temperature** based on historical weather data.

---

## Project Description
This project focuses on **time series forecasting** of air temperature using a deep learning model.  
The model learns from past temperature data to predict future values.

- **Dataset**: `AP003.csv` (includes air temperature and date columns)
- **Goal**: Predict future temperature values using historical patterns
- **Problem Type**: Regression

---

## Model Details
- **Architecture**: LSTM layers + Dense + Dropout
- **Framework**: TensorFlow / Keras
- **Metrics**: MAE, MSE, R²

---

## Tools & Libraries
- Python  
- TensorFlow / Keras  
- Pandas  
- Scikit-learn  
- Matplotlib  

---

## Results
The model successfully learned temporal patterns from the dataset  
and produced accurate forecasts for unseen data.
